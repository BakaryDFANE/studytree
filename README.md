# Study Tree

Application Flask pour organiser les études sous forme d’arbre.

## Lancer localement

```bash
pip install -r requirements.txt
python app.py
```

Puis ouvrir : http://127.0.0.1:5000

## Déploiement Vercel

1. Ajouter le projet sur Vercel.
2. Déployer avec la configuration présente dans `vercel.json`.
3. Vérifier que le fichier `requirements.txt` est bien présent.

## Fonctionnalités

- création de branches
- renommage et suppression
- arbre hiérarchique
- documents locaux
- liens Drive et externes
- sauvegarde automatique
